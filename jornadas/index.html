Jornadas independentes

Uma jornada não é um menu. Uma capacidade não é uma etapa. Uma tela não é uma etapa. Separe quando o gatilho, o resultado, os atores ou o lifecycle forem outros — e não force um fluxo linear por papel. Os 8 clusters abaixo são um grafo, não uma esteira.

Para mandar a um responsável, use Setores: cada página diz o que o time é dono, o que só participa e o que não é da conta deles.

  • dispara (consequência certa)
  • pode disparar (ramo)
  • em paralelo (lifecycle independente)
  • devolve (o ciclo anterior retoma)

O grafo é largo de propósito — role na horizontal. Passe o mouse num nó para ver só os handoffs dele. Clique para abrir a jornada, não um tour da sidebar.
